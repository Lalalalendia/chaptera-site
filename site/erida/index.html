Chaptera · Private workspace

Erida makes chapter translation easier to review.

Erida is a private, access-controlled workspace for preparing, translating and reviewing book chapters. An optional Google Drive connection exports the original text and draft translation into two editable folders selected by the account owner.

For authorized collaborators · No public registration

Translation workflow

Authorized team members prepare source chapters, queue machine translations and review the results. A machine-generated translation is a draft, not an automatic publication.

Editable Drive exports

For each completed translation job, Erida can create one source TXT and one translated TXT inside book subfolders under the two Drive folders explicitly approved by the owner. Ordinary re-exports reuse existing files instead of overwriting human edits.

Why Erida asks for Google Drive permission

Erida uses the https://www.googleapis.com/auth/drive.file permission. The Google account owner selects the intended folders during authorization. The integration uses this grant to:

  • check the selected folders and identify files created by the integration;
  • create editable source and translation TXT files inside those folders;
  • reuse previously exported file IDs while preserving subsequent edits;
  • read back newly created test files during an explicitly requested integration check.

Erida does not request general access to every file in the owner's Drive. This public page is informational; it does not log you in or ask for Google credentials.

The owner stays in control

Access is granted through Google's own consent screen. The permission can be revoked in Google Account connections. Revocation stops further authorized Drive requests; previously exported TXT files remain in the owner's Drive until removed there.

Кратко об Эриде

Эрида — закрытый рабочий сервис Chaptera для перевода и редактирования глав. После разрешения владельца Google-аккаунта сервис выгружает исходный текст и черновой перевод в две выбранные папки Google Drive. Повторный экспорт не должен перезаписывать уже отредактированные TXT-файлы. Подробности обработки данных приведены в политике конфиденциальности.
